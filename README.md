# Testare CyberSec (SIEM, XDR, VAPT, DFIR și OWASP)

Platformă profesională pentru evaluarea competențelor tehnice în securitate cibernetică. 
Sistemul permite testarea pe domenii critice precum monitorizare SIEM, arhitecturi XDR, testare de penetrare (VAPT), investigații digitale (DFIR) și riscuri OWASP. Include funcționalități de feedback educativ instantaneu.
https://zghibarta.github.io/testare-cybersec/
